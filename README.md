# DevelopersHub-Corporation-Data-Science-Analytics---Advanced-Internship-Tasks
This repository contains a collection of advanced data science and machine learning projects completed as part of the Data Science Internship at DevelopersHub Corporation. These tasks demonstrate core competencies in classification, clustering, time-series forecasting, and business-driven model optimization.

# Objective
The primary goal was to apply end-to-end data science pipelines to real-world datasets. This involved complex data cleaning, exploratory data analysis (EDA), advanced modeling using industry-standard libraries like scikit-learn, xgboost, and prophet, and model interpretability.

# Project Tasks

# Task 1: Term Deposit Subscription Prediction (XAI)
Goal:Predict whether a customer will subscribe to a bank term deposit based on marketing campaign data.
Key Actions: Performed categorical encoding on the UCI Bank Marketing dataset and trained a Random Forest classifier.
Interpretability: Implemented SHAP (Explainable AI) to interpret and visualize the model's decision-making process for specific customer profiles.

# Task 2: Customer Segmentation (Unsupervised Learning)
Goal: Group customers based on spending patterns to propose targeted marketing strategies.
Key Actions: Applied K-Means Clustering to the Mall Customers dataset.
Visualization: Utilized Principal Component Analysis (PCA) to reduce dimensions and visualize distinct customer segments.

# Task 3: Energy Consumption Time Series Forecasting
Goal: Forecast household energy usage using historical temporal patterns.
Key Actions: Resampled the Household Power Consumption dataset into daily intervals and engineered time-based lag features.
Model Comparison: Evaluated performance differences between Prophet (additive model) and XGBoost (gradient boosting).

# Task 4: Loan Default Risk & Cost Optimization
Goal: Predict loan default likelihood and optimize decision thresholds based on financial cost-benefit analysis.
Key Actions: Cleaned the Home Credit Default Risk dataset and handled high-cardinality numeric features.
Business Impact: Strategically adjusted the classification threshold to minimize total business costs, balancing the impact of False Positives vs. False Negatives.

# Conclusion:
These tasks validated core technical skills in Exploratory Data Analysis (EDA), Supervised Machine Learning, Time Series, and Business Intelligence. This work provides a data-driven framework for solving complex business problems while adhering to the internship’s professional standards.
